# ❌⭕ Tic‑Tac‑Toe

A complete two‑player Tic‑Tac‑Toe game that runs in the terminal. Two players take turns marking **X** and **O** on a 3×3 grid. The game detects wins (three in a row, column, or diagonal) and ties (when the board is full). You can play multiple rounds without restarting the script.

This project is an excellent exercise for learning Python basics: lists, loops, functions, and game logic. It's also a fun way to challenge a friend!

## ✨ Features

- **Two‑player turn‑based play** – Player X starts, then alternates with O.
- **Visual board display** – the grid is printed after every move, showing numbers 1‑9 as position references.
- **Win & tie detection** – automatically checks all winning combinations and declares the winner or a draw.
- **Input validation** – rejects out‑of‑range moves, occupied cells, and non‑numeric input. You can quit anytime with `'q'`.
- **Replay option** – after each game, decide to play again or exit.
- **Clean and modular code** – functions for board printing, win checking, and board‑full detection.

## 🚀 How to Run

1. Ensure you have **Python 3.6+** installed.
2. Clone the repository or download the `tictac.py` file.
3. Open your terminal and navigate to the script's folder.
4. Launch the game with:
